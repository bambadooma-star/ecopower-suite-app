Frequently Asked Questions

Does ECO mode kill my active downloads or background rendering?

No! Unlike aggressive sleep utilities, EcoPower Suite adjusts physical display backlight power and CPU performance state multipliers. Windows network stacks, active downloads, and background rendering tasks continue to run uninterrupted.

Will moving the mouse take me out of ECO mode?

Only if ECO mode was triggered automatically by inactivity (Auto-Idle). If you physically clicked the ECO SAVER button, it engages a strict Manual Lock that ignores mouse and keyboard movement until you explicitly choose to switch back.

Does it support multiple monitors?

Yes! EcoPower Suite enumerates all active monitors connected via HDMI, DisplayPort, or USB-C and applies DDC/CI hardware brightness commands across all compatible displays.

How does it start with Windows?

It registers directly into HKCU\...\CurrentVersion\Run with the --minimized flag. When your PC boots, it starts silently in the System Tray (notification area near the clock) without popping up any distracting windows.
