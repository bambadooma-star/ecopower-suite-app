## ✨ Features
- **🌿 ECO SAVER**: 10% DDC/CI hardware screen dimming + 30% CPU multiplier capping (~67W continuous savings).
- **⚖️ BALANCED**: 100% monitor brightness with adaptive Windows energy scaling.
- **⚡ MAX PERFORMANCE**: Unlocks full Turbo Boost and processor frequency headroom.
- **🌙 Scheduled Auto Shutdown**: Windows Task Scheduler integration with a polite 30-second warning alert, 1-hour snooze, or today cancellation.
- **💰 Financial Analytics Matrix**: Real-time wattage meter and breakdown matrix (Last Year, Next Year Forecast, Total Combined).
- **⚙️ Native Windows 11 Energy Hub**: 1-click deep links to native Windows Settings (`ms-settings:energyrecommendations`, `ms-settings:powersleep`).
